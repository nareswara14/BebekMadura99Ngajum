BEBEK MADURA 99 NGAJUM - Android WebView App

Aplikasi Android ini membuka Google Apps Script Web App BEBEK MADURA 99 NGAJUM.

Package: com.bebekmadura99.ngajum
Target SDK: 35
Min SDK: 23
Java: 17
Gradle: 8.7

Build tanpa Android Studio:
1. Upload semua file/folder project ke GitHub.
2. Pastikan .github/workflows/main.yml ikut di-upload.
3. Push/Commit ke branch main.
4. Buka Actions.
5. Tunggu workflow Build APK BEBEK MADURA 99 NGAJUM selesai.
6. Buka hasil run yang berhasil.
7. Pada bagian Artifacts, download BEBEK-MADURA-99-NGAJUM-APK.
